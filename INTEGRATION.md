# Developer Integration Cheat Sheet (1-Pager)

Quick copy-paste integration guide for teammates calling the Voice, Skill Card, and myScheme helper modules.

---

## 1. Standard `card_data` JSON Schema

Pass this dictionary format across all module functions:

```python
card_data = {
    "card_id": "WKR-2024-HI01",                             # Unique string ID
    "worker_name": "रमेश कुमार (Ramesh Kumar)",              # Worker display name
    "language": "hi",                                       # "en" | "hi" | "kn"
    "matched_role": "सहायक इलेक्ट्रीशियन (Assistant Electrician)", # Extracted job role
    "confirmed_skills": [                                   # List of verified skills
        "घरेलू वायरिंग (House Wiring)",
        "सर्किट रिपेयर (Circuit Repair)",
        "सोलर पैनल इंस्टालेशन"
    ],
    "next_course": "सोलर रूफटॉप तकनीशियन (Surya Mitra)",     # Upskilling recommendation
    "nearest_centre": "पीएमकेके कौशल केंद्र, सेक्टर 62, नोएडा", # Nearest training hub
    "public_card_url": "https://your-domain.com/verify/WKR-2024-HI01", # Live QR target
    "scheme_name": "पीएम सूर्य घर मुफ्त बिजली योजना"           # Optional scheme title
}
```

## 2. Skill Card Generator (`skill_card.py`)

### Generate Card PNG, Scannable QR & WhatsApp Link

```python
from skill_card import generate_skill_card_image, create_whatsapp_share_link, generate_qr_base64

# 1. Generate clean 800x1120 mobile PNG with embedded QR code (returns file path)
card_png_path = generate_skill_card_image(card_data, output_dir="./generated_cards")

# 2. Generate WhatsApp share link (https://wa.me/?text=...)
whatsapp_link = create_whatsapp_share_link(card_data)

# 3. (Optional) Generate raw Base64 PNG data URI for web/mobile UI display
qr_data_uri = generate_qr_base64(card_data["public_card_url"])
```

*Note: Font fallback automatically handles Hindi/Kannada if system fonts are missing without showing blank boxes.*

## 3. Voice Service (`voice_service.py`)

Supports **Hindi (`hi`)**, **English (`en`)**, and **Kannada (`kn`)**.

### A. Speech-to-Text (STT)

```python
from voice_service import transcribe_worker_voice

# Transcribe worker audio (.mp3, .wav, .webm, .ogg, < 10 MB)
stt_result = transcribe_worker_voice("incoming_recording.wav", language_hint="hi")
# Returns: {"status": "ok", "transcript": "...", "detected_language": "hi", "error": None}
user_text = stt_result["transcript"]
```

### B. Spoken Summary & Text-to-Speech (TTS) with Caching

```python
from voice_service import build_spoken_summary, generate_voice_output

# 1. Format natural plain-language script (cleans out transliteration brackets)
spoken_script = build_spoken_summary(card_data, language="hi") # or "en", "kn"

# 2. Synthesize MP3 using ElevenLabs eleven_v3 (with automatic local file caching)
tts_result = generate_voice_output(spoken_script, card_id=card_data["card_id"], language="hi", output_dir="./audio_cache")
# Returns: {"status": "ok", "audio_path": ".../WKR-2024-HI01_hi.mp3", "cached": False, "error": None}
audio_file_path = tts_result["audio_path"]
```

*Note: If `ELEVENLABS_API_KEY` is not set or rate-limited, it automatically outputs a playable fallback `.mp3` without throwing an exception.*

## 4. Official myScheme Links & Disclaimer (`extras_helper.py`)

```python
from extras_helper import get_official_schemes

# Pass any job role or category ('electrician', 'tailor', 'cook', 'plumber', 'driver', etc.)
schemes = get_official_schemes("electrician")
# Returns list of matching schemes with official myscheme.gov.in URLs and disclaimers
for s in schemes:
    print(s["scheme_name"])      # Official title
    print(s["official_url"])      # Verified https://www.myscheme.gov.in/ link
    print(s["one_line_benefit"]) # Concise benefit summary
    print(s["disclaimer"])        # "Verify eligibility on the official myScheme portal before applying."
```

## 5. Directory Structure & Cache

- **`./generated_cards/{card_id}.png`**: Mobile skill card images generated by `skill_card.py`.
- **`./audio_cache/{card_id}_{lang}.mp3`**: Cached speech output generated by `voice_service.py`. Subsequent calls return instantly (`cached=True`) with 0 API cost.
